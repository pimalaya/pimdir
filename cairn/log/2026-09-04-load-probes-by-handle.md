# A Handles load reads its own probes

load_probes is unscoped, so an upgrade of a batch read every unnamed handle of a freshly enumerated mailbox and filtered in memory. load_probes_by_handle binds the batch's handles as a JSON array; STORAGE §14 and GUIDE §9 name it for the Handles scope.
