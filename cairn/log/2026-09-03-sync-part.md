# The sync model joins the standard

§10 carried the state of the merge (`base_object`, `shared_object`, `deleted`, the two `conflicted` flags, the generation) and the transitions lived in io-replica's cairn, two documents describing one state machine from opposite sides.

Every merge defect of the summer (the hub level, the dedup base, the binding repoint, the two-endpoint loss) was a place where a vector over state plus remote snapshot would have caught it the way an object vector catches a hash.

SYNC.md folds the transitions in as a normative part with a status of its own: the projection from rows to placements (§3), the shape a connector hands the engine (§4), the five verbs (§5 to §8), several sources (§9), the write (§10).

Ten cases under vectors/sync/ pin the ordinary paths: a pulled flag, a pushed flag, a two-sided flag merge, a remote delete retaining, a local delete pushed, a probe, a `Meta` upgrade naming one, a read-only revert, cross-source propagation, a rekey. checks/vectors.py checks their shape and references; only an implementation runs one, and the reference implementation's suite is where they run.

The remote seam stays out of the standard: only the shape of what a source answers is fixed.
